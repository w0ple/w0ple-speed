# W0ple Speed

Клиентский мод Fabric для Minecraft 26.2. Два модуля:

- **Скоростная музыка.** Чем быстрее вы двигаетесь, тем громче песня. Она стартует с самого драйва (пик находится автоматически), короткие провалы скорости её не перезапускают, после 3 с ниже минимума она затихает и в следующий раз снова начнётся с пика. Пока играет, ванильная музыка молчит.
- **Проекции.** За быстро бегущим игроком остаются яркие полупрозрачные зелёные силуэты (только позади, не ближе ~1 блока к телу).

## Установка

1. Нужны Fabric Loader и Fabric API. Положи `w0ple-speed-1.0.2.jar` в папку `mods`.
2. Положи песню (`.mp3` или `.ogg`) в `config/w0plespeed/`. Берётся первый `.ogg` по имени; если `.ogg` нет, то первый `.mp3`. Песню мод не содержит и не скачивает; пока файла нет, музыка молчит.
3. Необязательно: Mod Menu + Cloth Config дают экран настроек (Mods -> W0ple Speed). Без них мод работает по файлу `config/w0plespeed.json`.

Если установлен W0ple Visuals (в нём те же функции), W0ple Speed сам отключается и пишет об этом в лог.

## Настройки (`config/w0plespeed.json`)

| Поле | По умолчанию | Смысл |
|---|---|---|
| `musicEnabled` | true | музыка вкл |
| `volume` | 100 | громкость, % (0-200) |
| `volumeBySpeed` | true | громкость растёт со скоростью |
| `minSpeed` / `maxSpeed` | 8 / 40 | блоков/с: с какой скорости играет / полная громкость |
| `peakSeconds` | -1 | секунда старта песни, -1 = авто (найденный пик хранится в `peakFile/peakSize/peakValue`) |
| `afterimagesEnabled` | true | проекции вкл |
| `threshold` | 40 | порог скорости для проекций, бл/с |
| `color` | #7CFFB2 | цвет |
| `brightness` | 1.0 | яркость 0.2-1.0 |
| `life` | 0.4 | время жизни слепка, с |
| `interval` | 2 | слепок раз в N тиков |
| `onlyMe` | false | только свои проекции |

## Сборка

`gradlew build` (Java 25). Тесты: `gradlew test`, проверка в игре: `gradlew runGametest`.

## Зависимости и лицензии

Для воспроизведения `.mp3` мод включает библиотеку [JLayer](https://github.com/umjammer/jlayer) 1.0.1 (`javazoom:jlayer`, лицензия LGPL-2.1). Она лежит в моде отдельным вложенным jar (`META-INF/jars/jlayer-1.0.1.jar`), без перепаковки классов, поэтому её можно заменить своей сборкой.
